# A brief desciption
FindAM is a full-stack web application that allows users to report lost or found items within their community. Users can upload images and details of the items, which are securely stored in an AWS S3 bucket. The application features a responsive user interface built with React, and a robust backend powered by Node.js and MongoDB. With FindAM, we're making it easier to help people recover their lost possessions and bring communities together.
